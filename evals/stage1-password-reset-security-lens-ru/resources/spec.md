# ТЗ: Восстановление пароля

Версия 0.9 · Владелец: команда «Аккаунт» · Статус: готово к разработке

## 1. Назначение
Пользователь, забывший пароль, может задать новый пароль через ссылку из письма.

## 2. Запрос восстановления
1. На странице входа есть ссылка «Забыли пароль?», ведущая на форму с полем «Email».
2. После нажатия «Отправить» система ищет пользователя по email.
3. Если пользователь найден, на его email отправляется письмо со ссылкой для сброса пароля и показывается сообщение «Письмо отправлено».
4. Если пользователь не найден, показывается сообщение «Пользователь с таким email не зарегистрирован».

## 3. Ссылка для сброса
1. Ссылка содержит уникальный токен.
2. По ссылке открывается форма «Новый пароль» и «Повторите пароль».
3. Новый пароль должен быть надёжным.

## 4. Смена пароля
1. Если пароли в двух полях совпадают, пароль меняется и пользователь перенаправляется на страницу входа.
2. Если пароли не совпадают, показывается сообщение «Пароли не совпадают».
3. После смены пароля пользователю отправляется уведомление на email.

## 5. Вне рамок
Вход через соцсети, двухфакторная аутентификация.
