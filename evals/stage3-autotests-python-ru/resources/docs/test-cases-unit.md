# Unit-кейсы — Ценообразование корзины

### TC-UNIT-001: Количество 0 и 21 недопустимо, 1 и 20 — допустимо
- **Трассировка:** REQ-1
- **Техника:** Анализ граничных значений — количество: 0, 1, 20, 21
- **Уровень:** Unit — `is_valid_quantity` — чистая функция
- **Приоритет:** P2
- **Предусловия:** нет
- **Тестовые данные:** 0, 1, 20, 21
- **Шаги:**
  1. Вызвать `is_valid_quantity` для каждого значения
- **Ожидаемый результат:** 1 и 20 → True; 0 и 21 → False

### TC-UNIT-002: Сумма корзины из нескольких строк равна сумме цена × количество
- **Трассировка:** REQ-2
- **Техника:** Эквивалентное разбиение — класс «несколько строк»
- **Уровень:** Unit — арифметика без ввода-вывода
- **Приоритет:** P1
- **Предусловия:** нет
- **Тестовые данные:** (100,00 × 2), (49,50 × 3)
- **Шаги:**
  1. Вызвать `subtotal` для двух строк
- **Ожидаемый результат:** 348,50

### TC-UNIT-005: Скидка участника 5% действует только при сумме от 3000 вне распродажи
- **Трассировка:** REQ-4, A1
- **Техника:** Таблица решений — участник × сумма ≥ 3000 × распродажа (правила R1–R4)
- **Уровень:** Unit — `member_discount` — чистая функция
- **Приоритет:** P0
- **Предусловия:** нет
- **Тестовые данные:** R1: участник, 3000,00, нет распродажи → 150,00; R2: не участник, 3000,00, нет распродажи → 0,00; R3: участник, 2999,99, нет распродажи → 0,00; R4: участник, 3000,00, распродажа → 0,00
- **Шаги:**
  1. Вызвать `member_discount` для каждого правила
- **Ожидаемый результат:** R1 → 150,00; R2, R3, R4 → 0,00
