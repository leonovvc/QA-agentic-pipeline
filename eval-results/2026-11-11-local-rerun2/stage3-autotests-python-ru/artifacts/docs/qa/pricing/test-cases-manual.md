# Ручные кейсы — Ценообразование корзины

### TC-MAN-001: Исследовательская сессия: отображение скидки участника в корзине
- **Трассировка:** REQ-4
- **Техника:** Исследовательский чартер — миссия: найти расхождения в отображении скидки
- **Уровень:** Ручной — нет стабильного оракула для текста и вёрстки
- **Приоритет:** P2
- **Предусловия:** тестовый аккаунт участника
- **Тестовые данные:** корзины на 2999,99 и 3000,00
- **Шаги:**
  1. 45 минут исследовать отображение скидки в корзине и в письме
- **Ожидаемый результат:** заметки сессии со списком найденных проблем
