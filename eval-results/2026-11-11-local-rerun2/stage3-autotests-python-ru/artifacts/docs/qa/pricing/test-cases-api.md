# API-кейсы — Ценообразование корзины

### TC-API-001: Ответ корзины содержит бесплатную доставку при сумме 5000,00
- **Трассировка:** REQ-3
- **Техника:** Анализ граничных значений — сумма 5000,00 через API
- **Уровень:** API — проверка, что сервис корзины использует то же правило
- **Приоритет:** P0
- **Предусловия:** сервис корзины доступен по `CART_API_URL`; корзина C1 на сумму 5000,00
- **Тестовые данные:** корзина C1
- **Шаги:**
  1. `GET /carts/C1`
- **Ожидаемый результат:** `200`, `shipping = 0.00`
