# Тест-кейсы: unit — расчёт стоимости корзины (`shop.pricing`)

Задача: cart-pricing-f9ae3c · ТЗ: `specs/cart-pricing.md` v1.2 · План: `test-plan.md`.
Все суммы — `Decimal`. Кейсы автоматизируются в `tests/` репозитория (pytest).

### TC-UNIT-001: Количество 1..20 допустимо, 0, -1 и 21 — недопустимо
- **Трассировка:** REQ-3, A7
- **Техника:** Анализ граничных значений — `quantity`: min-1 (0), min (1), min+1 (2), max-1 (19), max (20), max+1 (21); плюс отрицательное -1 как недопустимый класс
- **Уровень:** Unit — чистая функция `is_valid_quantity(quantity)` без ввода-вывода
- **Приоритет:** P1
- **Предусловия:** Модуль `shop.pricing` импортируется; состояние не требуется
- **Тестовые данные:** quantity = 0, 1, 2, 19, 20, 21, -1 (целые, A7)
- **Шаги:**
  1. Вызвать `is_valid_quantity(0)` → Ожидается: `False`
  2. Вызвать `is_valid_quantity(1)` → Ожидается: `True`
  3. Вызвать `is_valid_quantity(2)` → Ожидается: `True`
  4. Вызвать `is_valid_quantity(19)` → Ожидается: `True`
  5. Вызвать `is_valid_quantity(20)` → Ожидается: `True`
  6. Вызвать `is_valid_quantity(21)` → Ожидается: `False`
  7. Вызвать `is_valid_quantity(-1)` → Ожидается: `False`
- **Ожидаемый результат:** значения 1, 2, 19, 20 дают `True`; значения 0, 21, -1 дают `False`

### TC-UNIT-002: Сумма корзины из нескольких строк с копейками = сумма «цена × количество»
- **Трассировка:** REQ-6, A8
- **Техника:** Разбиение на классы эквивалентности — класс «несколько строк, цена с копейками» (класс «одна строка» уже покрыт существующим `test_subtotal_multiplies_price_by_quantity`)
- **Уровень:** Unit — чистая функция `subtotal(lines)`
- **Приоритет:** P1
- **Предусловия:** Модуль `shop.pricing` импортируется
- **Тестовые данные:** строка 1: `sku=MUG-01`, price `450.00`, quantity 3; строка 2: `sku=PEN-02`, price `99.99`, quantity 2
- **Шаги:**
  1. Вызвать `subtotal([CartLine("MUG-01", Decimal("450.00"), 3), CartLine("PEN-02", Decimal("99.99"), 2)])` → Ожидается: результат `Decimal("1549.98")` (1350.00 + 199.98)
- **Ожидаемый результат:** `subtotal` равен `Decimal("1549.98")`
