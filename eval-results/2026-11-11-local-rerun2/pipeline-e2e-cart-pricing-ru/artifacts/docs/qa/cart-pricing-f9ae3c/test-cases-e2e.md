### TC-E2E-001: Попытка поставить количество 21 показывает ошибку, количество остаётся 20
- **Трассировка:** REQ-5, REQ-3, A7
- **Техника:** Анализ граничных значений — `quantity`, max+1 (21) через UI; граница как таковая проверена на unit (TC-UNIT-001), здесь проверяется связка UI с правилом
- **Уровень:** E2E — «количество в строке не меняется» наблюдается только в состоянии страницы корзины
- **Приоритет:** P2
- **Предусловия:** Покупатель открыл страницу корзины; в корзине одна строка `MUG-01`, цена 450.00, количество 20
- **Тестовые данные:** новое значение количества `21`; текст ошибки не проверяется (Q6)
- **Шаги:**
  1. В поле количества строки `MUG-01` ввести `21` и подтвердить → Ожидается: рядом со строкой виден элемент с сообщением об ошибке (непустой текст)
  2. Обновить страницу корзины → Ожидается: в поле количества строки `MUG-01` значение `20`
- **Ожидаемый результат:** сообщение об ошибке было показано, количество в строке `MUG-01` равно `20` и после перезагрузки страницы

### TC-E2E-002: Сумма корзины 4000.00 — показана строка «До бесплатной доставки осталось 1000 ₽»
- **Трассировка:** REQ-19, A9, A10
- **Техника:** Разбиение на классы эквивалентности — класс «сумма ниже порога»; N = 5000.00 − сумма (A9)
- **Уровень:** E2E — связка «страница показывает строку рядом с итогом» проверяется только в UI; сами суммы проверены на unit/API
- **Приоритет:** P2
- **Предусловия:** Покупатель не участник; в корзине одна строка `MUG-01`, цена 4000.00, количество 1
- **Тестовые данные:** ожидаемый текст соответствует шаблону `^До бесплатной доставки осталось 1[  ]?000([.,]00)? ₽$` (A10: допускается разделитель тысяч и «,00»)
- **Шаги:**
  1. Открыть страницу корзины → Ожидается: рядом с блоком итога виден текст, подходящий под шаблон
- **Ожидаемый результат:** строка о доставке видна рядом с итогом и подходит под шаблон из тестовых данных

- **Уровень:** E2E — скрытие элемента на странице проверяется только в UI
- **Приоритет:** P2
- **Предусловия:** Покупатель не участник; в корзине одна строка `MUG-01`, цена 5000.00, количество 1
- **Тестовые данные:** сумма корзины 5000.00
- **Шаги:**

- **Ожидаемый результат:** строка «До бесплатной доставки осталось …» на странице отсутствует; в блоке итога показан итог 5000.00 (доставка бесплатная)
