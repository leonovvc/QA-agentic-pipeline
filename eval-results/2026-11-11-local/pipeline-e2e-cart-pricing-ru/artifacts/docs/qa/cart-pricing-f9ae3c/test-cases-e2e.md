- **Level:** E2E — только через UI видно, что ошибка показана и значение в поле осталось прежним; граница сама проверена на unit и API
- **Priority:** P1
- **Preconditions:** [НЕТ РЕАЛИЗАЦИИ] Покупатель не участник; в корзине одна строка `MUG-01`, цена 450.00, количество 5; итог на странице 2550.00 ₽ (2250.00 + доставка 300.00)
- **Test data:** новое количество `21`
- **Steps:**
  1. Открыть страницу корзины → Expected: у строки `MUG-01` в поле количества стоит 5
  2. Ввести `21` в поле количества и подтвердить (Enter) → Expected: рядом со строкой виден элемент с ошибкой (текст не задан ТЗ, Q4)
  3. Прочитать поле количества и итог → Expected: в поле снова 5, итог 2550.00 ₽
- **Expected result:** ошибка отображается; количество в строке равно 5; итог равен 2550.00 ₽
